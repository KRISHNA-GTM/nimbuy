# nimbuy — krishna-gtm.github.io/nimbuy

Plain HTML, CSS and JavaScript. **No build step, no framework.** The repo root is the site.

```
index.html              the whole site
css/style.css           styling
js/listing-check.js     the 7-dimension listing audit, runs in the browser
js/listing-benchmark.js aggregates only, generated by tools/build-benchmark.js
js/enquiry.js           offer briefs -> a ready-written email (no CRM, nothing stored)
js/assistant.js         offline offer guide (no AI, no network)
js/main.js              nav, reveals, chart, count-up
assets/                 favicon, founder photo, og.png
```

## Change something

Edit `index.html` directly, commit, push. The workflow publishes the repo root as-is.
To try a variation, copy `index.html` to a new name and work on the copy.

## Run locally

```bash
python -m http.server 5175
```

## Refresh the benchmark

```bash
node ../tools/build-benchmark.js path/to/listings_<date>.csv
```

## Moving to nimbuy.io later

1. Add a `CNAME` file containing `nimbuy.io`.
2. Replace `https://krishna-gtm.github.io/nimbuy/` in `index.html`, `robots.txt` and
   `sitemap.xml` with `https://nimbuy.io/`.
3. DNS: A records `@` -> 185.199.108.153 / .109.153 / .110.153 / .111.153;
   CNAME `www` -> `krishna-gtm.github.io`. Settings -> Pages -> custom domain -> Enforce HTTPS.

No employer names or employer work on this site. Never commit the reference PDFs or the
internal .pptx that sit in the local working folder.
